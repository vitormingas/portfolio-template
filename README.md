# Protótipo de Portfólio Pessoal | Trilha Front-end

Este repositório contém a entrega da prototipação do meu portfólio pessoal construído no Figma, referente ao entregável de Design de Experiência da Trilha Front-end. O projeto apresenta minha identidade visual, trajetória e habilidades utilizando o meu apelido "mingas".

## ⚠️ Sobre o Template
Este design foi estruturado como um template base. Optei por deixar algumas seções, textos e áreas de projetos com informações de marcação (placeholder) para serem preenchidas de forma definitiva futuramente, conforme meu aprendizado e desenvolvimento de novos projetos na área avancem.

## 📌 Estrutura do Projeto

O protótipo foi estruturado para atender a todos os requisitos do desafio, contendo as seguintes seções:
* **Apresentação:** Uma seção inicial apresentando quem sou, com avatar estilizado e chamadas para ação (Download CV e View Projects).
* **Stacks / Habilidades:** Uma área dedicada à exibição das tecnologias que domino, destacando HTML, CSS e JavaScript.
* **Projetos:** Uma galeria para apresentar os trabalhos desenvolvidos.
* **Página Individual do Projeto:** Uma tela de aprofundamento para projetos específicos, contendo visão geral, lista de *features*, *tech stack* utilizada e botões de redirecionamento (GitHub e Live Demo).
